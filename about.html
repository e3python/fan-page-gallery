From Structure to Style

Bringing web pages to life with professional design techniques.

Building Real Websites

In Stage 1, students learned the foundation: how to organize information using semantic HTML. Now in Stage 2, they're adding the design layer that makes websites beautiful and functional.

This is where web design comes alive. Students learn to use CSS stylesheets—the same professional tool used by designers at companies like Google, Apple, and Netflix. They discover how colors, fonts, spacing, and images transform plain text into engaging visual experiences.

The Engineering Constraints

Every page in this gallery was built under these professional web development standards:

✅ External Stylesheets Only

All CSS lives in separate .css files. This is how professionals work—it keeps code clean and makes websites easier to maintain.

✅ No Inline Styles

Students cannot style individual HTML tags directly. This constraint reinforces the professional principle of separation of concerns—keeping structure separate from design.

✅ Images Included

Students learn file paths, image formats, and how to incorporate media responsibly into their designs.

✅ Semantic HTML Foundation

The strong structure from Stage 1 remains. Good design starts with good structure.

What Parents Should Notice

When reviewing your student's project, look for:

🎨 Thoughtful color choices 📝 Readable typography 🖼️ Relevant imagery 📐 Intentional spacing and alignment ✨ Visual hierarchy that makes sense

Most importantly: Does the design enhance the content? A beautiful website should tell a clear story.
